# 06 – Manual de Usuario
## 1. Acceso
Abra la aplicación desde el navegador. En la pantalla inicial seleccione **Iniciar Sesión** o **Registrarse**.

## 2. Registro
Ingrese nombre, correo y contraseña. El sistema valida que los campos estén completos y que el correo no esté registrado.

## 3. Inicio de sesión
Ingrese correo y contraseña. Si las credenciales son correctas, se muestra el área principal.

## 4. Cargar documento
Seleccione un archivo PDF, DOCX o TXT y utilice la opción de carga. El sistema guarda el archivo, extrae su contenido y solicita a la IA una categoría y un resumen.

## 5. Consultar documentos
En el listado se pueden visualizar los documentos procesados, su tipo, categoría y resumen.

## 6. Preguntar a la IA
Escriba una pregunta relacionada con la información almacenada y envíela. La respuesta se genera utilizando el contexto documental disponible.

## 7. Eliminar
Use la opción de eliminación asociada al documento. Confirme la operación cuando la interfaz lo solicite.

## 8. Recomendaciones
No cargue información personal real sin autorización. Para las demostraciones académicas se recomienda utilizar los archivos sintéticos incluidos en `documentos_prueba/`.
